# About Me

My name is **Efe**. I am a student interested in mechanical engineering, vehicle systems, materials, and understanding how technical designs become physical objects.

I want to use digital fabrication to improve my ability to design, manufacture, test, and refine prototypes. This website records the methods and reasoning behind my work.

## Goals

- Produce reproducible technical documentation.
- Connect digital design with manufacturing.
- Evaluate prototypes using measurements and observations.
- Use version control to preserve project history.
